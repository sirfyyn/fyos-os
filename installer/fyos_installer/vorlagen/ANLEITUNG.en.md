## Important

- Secrets live only in `{{geheimdatei}}` (mode 0600). The file does not belong in Git or in messages; a `.gitignore` is in place.
- The hub is built as its own image (`hub/Dockerfile`): the distribution's hub plus the chosen plugin packages. Packages from Git addresses need `git` in the base image and access to the repository.
- Plugin packages are installed by `uv` instead of `pip`. Your own package index (environment variable `FYOS_PAKETINDEX`, passed as build argument `FYOS_INDEX_URL`) comes before PyPI, and `uv` takes a package only from the first index that has it: a package with the same name on PyPI cannot replace your own.
- The agent is the Runner (`fyos-agent/runner`). Its configuration is in `agent-runner.json` (schema: `fyos-agent/runner/beispiele/agent-runner.beispiel.json`); restart the agent after changes. Matrix as a notification channel is added there by hand (`pi_durable.freigabe_meldung.kanaele`).
- The interface language is set in `fyos.config.json` (`"sprache": "en"` or `"de"`); each user can also switch it under Settings › Appearance › Language.
- If something does not run, `{{protokoll_befehl}}` shows the messages.
